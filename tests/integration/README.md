# Local integration tests (headless)

Headless integration tests exercise **SshWorker** core paths (connect, ProxyJump, SFTP, keepalive/compression) against a local container stack. No GUI.

## Prerequisites

- Qt 6.6+, libssh, CMake 3.28+
- **Podman** (preferred) or Docker
- `podman-compose` (preferred on Fedora) or `podman compose` / `docker compose`

Runtime detection prefers **podman** when both are installed.

## Quick start

```bash
# 1. Start the SSH lab stack
chmod +x tests/integration/scripts/*.sh
tests/integration/scripts/up.sh

# 2. Build and run tests
tests/integration/scripts/run-tests.sh

# 3. Stop the stack
tests/integration/scripts/down.sh
```

## Stack topology

| Service | Host port | Role |
|---------|-----------|------|
| `ssh-direct` | 127.0.0.1:12222 | Direct SSH baseline |
| `bastion1` | 127.0.0.1:12223 | Jump host (1 hop) |
| `bastion2` | 127.0.0.1:12224 | Jump host (multi-hop, future) |
| `ssh-target` | *(not published)* | Final target, reachable via bastion |
| `internal-app` | *(private only)* | nginx for future tunnel tests |

Credentials are defined in `fixtures/endpoints.env` (regenerated by `up.sh`).

Bastion1 defines two users for credential scenarios:

| User | Password | Used when |
|------|----------|-----------|
| `jump1` | `passapp` (same as target) | ProxyJump with “same credentials as target” |
| `gateway` | `passjump1` | ProxyJump with separate gateway password |

## Manual CMake

```bash
cmake --preset integration
cmake --build --preset integration --target easy-ssh-integration-tests
source tests/integration/fixtures/endpoints.env
./build-integration/tests/integration/easy-ssh-integration-tests
```

Tests auto-skip if the stack is not reachable.

## Test cases

- Direct connect + shell echo
- Direct SFTP list directory
- ProxyJump 1 hop (same credentials as target)
- ProxyJump with separate gateway password
- Wrong gateway password → error mentions gateway/connection failure
- Compression enabled connect
- Keepalive enabled (short interval smoke)
